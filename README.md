# CV & Portofolio Pribadi Interaktif

Website CV/Portofolio Pribadi modern yang dilengkapi:
- **Frontend**: HTML5 Semantik, CSS3 (Glassmorphism, 3D Hover Tilt, Print-friendly `@media print`), Vanilla JS ES6+, Chart.js, Typed.js.
- **Backend & Database**: `@netlify/database` (PostgreSQL otomatis) dan `@netlify/functions` (`/api/portfolio` & `/api/contact`).
